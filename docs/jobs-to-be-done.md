# Jobs To Be Done

Why people use the Tip & Bill Splitter. Each job names the role it belongs to (see [app-roles.md](app-roles.md)).

---

## Organizer jobs

### J1 — Split a bill evenly, fast
**Role:** Organizer

When the bill arrives and everyone is waiting to leave, I want to enter the total and the number of people and see one amount per person right away, so I can tell everyone what to pay without doing the maths by hand.

### J2 — Get tax and service charge right
**Role:** Organizer

When the bill shows tax and a service charge (and sometimes already includes tax), I want the app to handle them the way the receipt does, so I can trust the final total matches what the restaurant charges.

### J3 — Leave a fair tip without arguing about it
**Role:** Organizer

When it's time to tip, I want to pick a common tip percent, type my own, or choose no tip, so I can settle the tip quickly and know exactly how much it adds.

### J4 — Split unevenly when people ordered different things
**Role:** Organizer

When some people ordered much more than others, I want to enter what each person owes and have tax, service and tip shared out in proportion, so I can charge everyone fairly instead of splitting evenly.

### J5 — Split in the local currency
**Role:** Organizer

When I'm paying in a currency other than my usual one, I want to pick that currency, so I can see amounts in the same money the bill is in.

### J6 — Pick up where I left off
**Role:** Organizer

When I close the tab or my phone locks before everyone has paid, I want my split to still be there when I come back, so I can finish collecting money without entering everything again.

### J7 — Start a new split cleanly
**Role:** Organizer

When I'm done with one bill and have another one, I want to clear everything in one step, so I can start fresh without old numbers mixing in.

---

## Table Guest jobs

### J8 — Know exactly what I owe
**Role:** Table Guest

When the Organizer says the split is ready, I want to find my name and see my amount, so I can pay or send the right money.

### J9 — Check the split is fair
**Role:** Table Guest

When I'm asked to pay an amount, I want to see how the total was built and what share I'm paying, so I can trust I'm not overpaying.

### J10 — Tip what I want to tip
**Role:** Table Guest

When people at the table want to tip different amounts, I want to set my own tip percent, so I can pay only the tip I chose.
